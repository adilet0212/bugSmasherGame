# 🐞 Bug Smasher Game

A fun browser-based game where players try to catch a moving bug with their mouse.  
As the player’s score increases, the bug’s speed and difficulty also increase.

---

## 🌐 Live Demo
Play here → **[Bug Smasher Game](https://adilet0212.github.io/bugSmasherGame/)**  

---

## 🎮 How to Play
1. The bug appears randomly on the screen.  
2. Click the bug to earn points.  
3. The bug’s movement speed increases as your score rises.  
4. Try to reach the highest score before you miss too many clicks!

---

## 🧠 Features
- Interactive mouse-based gameplay  
- Dynamic difficulty scaling  
- Background graphics and animations  
- Simple, lightweight, and runs fully client-side  

---

## 🧰 Tech Stack
- **HTML5** — game layout  
- **CSS3** — styling and animations  
- **JavaScript** — core game logic and interactivity
